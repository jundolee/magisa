# 피드와 AI 요약 디자인 비교

- `index.html`: 모바일 피드 현재 구조와 개선안
- `desktop.html`: PC 피드와 AI 요약 현재 구조와 개선안 (`#summary`로 요약 화면 진입)
- `content.json`: 두 피드 목업에 공통으로 사용한 2026-10-22 콘텐츠 표본

프로젝트 루트에서 정적 서버를 띄워 열 수 있습니다. 현재안은 코드·운영 화면을 참고한 재현이며 픽셀 캡처가 아닙니다. 요약 문구는 디자인 예시입니다.

## 선택된 구현

피드에는 개선안을 적용합니다. PC에서는 주제·블로그 탐색을 좌측에 배치하고 읽기 영역을 720px 이내로 유지합니다. 모바일에서는 탐색을 접고 소개를 줄이며, 제목을 주요 정보로 강조합니다. 검색·필터·읽음·즐겨찾기·공유·페이지 이동은 기존 실제 데이터와 서버 액션을 사용합니다.

AI 요약은 현재 디자인을 유지합니다. 개선 요약 목업은 비교용으로만 보관하며 실제 ArticlePreviewPanel에는 반영하지 않습니다.
